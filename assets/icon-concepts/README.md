# appfit icon concepts

These three 1254 px concepts were generated with the built-in image-generation
tool for the v0.3 macOS UI revamp. All use an ocean-blue compatibility/fitting
metaphor without text or a literal Apple hardware silhouette.

- `appfit-concept-a.png` — app grid nested inside an open four-corner frame.
- `appfit-concept-b.png` — app tile descending into a fitted tray.
- `appfit-concept-c.png` — nested rounded forms with a precise central fit.

Concept C is the production source because its silhouette remains clear at
16–32 px and its edge-to-edge blue layer is cleanly masked by macOS without the
dark corner pixels present in concept A. The reviewed 1024 px build input lives
at `../appfit-icon-1024.png`.

Shared prompt constraints: premium contemporary macOS utility icon, minimal
vector-friendly 3D treatment, generous safe margin, ocean-blue palette, no text,
logos, trademarks, floppy disk, Python logo, download-arrow cliché, or literal
Apple hardware.
